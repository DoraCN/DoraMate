## 背景与目标

在 DoraMate 的 v1.0 就绪路线图中，C# 绑定从"可用的 SDK"升级为"可分发的产品"是一个关键节点。改造前：

- **DoraNode** / **DoraOperator** 只有源码项目和示例项目，用户需手动引用或复制代码
- 没有 NuGet 包，无法通过标准 .NET 包管理分发
- 没有 `dotnet new` 模板，用户需从零搭建项目结构
- 前端"添加节点"面板中没有 C# 模板入口

**阶段二目标**，如计划文档所述：

> 将现有的 C# SDK 从"源码引用 + 示例项目"升级为"NuGet 包 + dotnet new 模板 + 前端模板库"，让用户可以在 3 步内创建一个新的 C# Dora 节点。

---

## 总体架构

```
用户工作流:
  1. dotnet new dora-node -n MyNode
  2. cd MyNode
  3. dotnet build
  → 完成

支撑层:
  ┌───────────────────────────┐
  │  NuGet 包                 │
  │  DoraMate.DoraNode        │────────── dotnet new 模板依赖
  │  DoraMate.DoraOperator    │────────── dotnet new 模板依赖
  └───────────┬───────────────┘
              │ 原生 C ABI 动态库
              ▼
  ┌───────────────────────────┐
  │  原生层 (Rust)             │
  │  dora-node-api-c          │
  │  dora-operator-api-c      │
  └───────────────────────────┘

脚本层:
  package-nuget.ps1     → NuGet 包构建
  build-templates.ps1   → 模板包构建 + 安装
  install-templates.ps1 → 从本地路径安装模板
  smoke-csharp-bindings.ps1 → 集成验证（含模板 smoke）

前端集成:
  api.rs → builtin_csharp_templates() → "添加节点"面板
```

## 实施内容

### 1. NuGet SDK 打包

#### DoraNode (`src/DoraNode/`)

```xml
<PackageId>DoraMate.DoraNode</PackageId>
<Version>0.2.0</Version>
```

- 同步/异步事件读取（`Next()` / `NextAsync()`）
- Arrow RecordBatch 全类型读写（`TryGetInt32`、`TryGetFloat`、`TryGetDate32` 等 15+ 投影方法）
- 跨平台原生库嵌入（`runtimes/win-x64`、`linux-x64`、`osx-x64`）
- 依赖：`Apache.Arrow` 22.1.0

#### DoraOperator (`src/DoraOperator/`)

```xml
<PackageId>DoraMate.DoraOperator</PackageId>
<Version>0.2.0</Version>
```

- NativeAOT 导出的 operator 生命周期（`Init` / `OnInput` / `OnInputClosed` / `OnError` / `Drop`）
- Arrow RecordBatch 契约式验证（`IArrowRecordBatchContract<TModel>`）
- 回归测试工具集（`OperatorRegressionRunner`）
- 跨平台原生库嵌入
- 依赖：`Apache.Arrow` 22.1.0、`System.Runtime.CompilerServices.Unsafe` 6.0.0

#### 打包脚本 (`scripts/package-nuget.ps1`)

```powershell
# DoraNode
dotnet pack src/DoraNode/DoraNode.csproj -c Release -o artifacts/nuget/ `
  -p:Authors="DoraMate" -p:RepositoryUrl=https://github.com/dora-rs/doramate

# DoraOperator
dotnet pack src/DoraOperator/DoraOperator.csproj -c Release -o artifacts/nuget/ `
  -p:Authors="DoraMate" -p:RepositoryUrl=https://github.com/dora-rs/doramate
```

- 构建解决方案 → 打包两个 SDK，统一输出到 `artifacts/nuget/`
- 支持 `-SkipBuild` 参数跳过编译直接打包

### 2. dotnet new 模板

两个 `dotnet new` 模板，位于 `templates/` 目录。

#### dora-node 模板

结构：

```
templates/dora-node/
├── .template.config/
│   └── template.json
├── CSharpNode.csproj        # sourceName: CSharpNode → 输出 <ProjectName>.csproj
└── CSharpNode.cs            # sourceName: CSharpNode → 输出 <ProjectName>.cs
```

模板源代码（`CSharpNode.cs`）使用真实的 SDK API：

```csharp
using DoraNode;

class Program
{
    static void Main(string[] args)
    {
        using var node = new DoraNode.DoraNode();
        while (true)
        {
            using var ev = node.Next();
            if (ev is null) break;
            // 处理事件、发送输出...
        }
    }
}
```

**模板参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--NodeName` | `MyDoraNode` | Entry-point class / namespace |
| `--TargetFramework` | `net8.0` | 目标框架（`net8.0` / `net9.0`） |

**template.json 身份标识：** `DoraMate.DoraNode.Template`

#### dora-operator 模板

结构：

```
templates/dora-operator/
├── .template.config/
│   └── template.json
├── CSharpOperator.csproj    # sourceName: CSharpOperator → 输出 <ProjectName>.csproj
├── CSharpOperator.cs        # sourceName: CSharpOperator → 输出 <ProjectName>.cs
└── NativeExports.cs         # UnmanagedCallersOnly 入口点（网关卡）
```

模板源代码（`CSharpOperator.cs`）演示完整的 operator 生命周期：

```csharp
public sealed class MyOperator : DoraOperatorBase
{
    protected override InitResult Init() { ... }
    protected override OnEventResult OnInput(InputEvent ev, OperatorOutput output) { ... }
    protected override OnEventResult OnInputClosed(InputClosedEvent ev, OperatorOutput output) { ... }
    protected override OnEventResult OnError(ErrorEvent ev, OperatorOutput output) { ... }
}
```

`NativeExports.cs` 提供三个 `UnmanagedCallersOnly` 入口点，将 operator 暴露为 C ABI：

- `dora_init_operator` → `OperatorEntrypoint<MyOperator>.InitOperator()`
- `dora_drop_operator` → `OperatorEntrypoint<MyOperator>.DropOperator()`
- `dora_on_event` → `OperatorEntrypoint<MyOperator>.OnEvent()`

**模板参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--OperatorName` | `MyOperator` | Operator 类名和文件名 |
| `--TargetFramework` | `net8.0` | 目标框架（`net8.0` / `net9.0`） |

**template.json 身份标识：** `DoraMate.DoraOperator.Template`

> **设计决策：** 模板使用真实的 SDK API 而非计划文档中的简化 API。计划文档中的 `DoraNode.Create()` / `await node.RunAsync()` 为预期设计方向，但尚未在 SDK 中实现。

### 3. 模板包 (Template Pack)

`templates/DoraMate.Templates.csproj` 是一个**内容仅打包**的项目（`PackageType=Template`），它不编译代码，而是将两个模板目录打包为 NuGet `DoraMate.Templates.*.nupkg`：

```xml
<PackageType>Template</PackageType>
<IncludeContentInPack>true</IncludeContentInPack>
<IncludeBuildOutput>false</IncludeBuildOutput>
<Content Include="dora-node\**\*" Exclude="dora-node\**\bin\**;dora-node\**\obj\**" />
<Content Include="dora-operator\**\*" Exclude="dora-operator\**\bin\**;dora-operator\**\obj\**" />
```

构建脚本 `scripts/build-templates.ps1`：

1. `dotnet pack` → 生成 `.nupkg` 到 `artifacts/templates/`
2. `dotnet new install` → 将模板注册到当前 .NET SDK
3. 完成后可通过 `dotnet new dora-node` / `dotnet new dora-operator` 调用

### 4. 自动化脚本

| 脚本 | 说明 | 路径 |
|------|------|------|
| `package-nuget.ps1` | 打包两个 SDK 为 NuGet 包 | `scripts/package-nuget.ps1` |
| `build-templates.ps1` | 构建模板包并安装到 dotnet new | `scripts/build-templates.ps1` |
| `install-templates.ps1` | 从本地路径直接安装模板（不开包） | `scripts/install-templates.ps1` |
| `smoke-csharp-bindings.ps1` | 集成 smoke 测试（含模板验证步骤） | `scripts/smoke-csharp-bindings.ps1` |

**install-templates.ps1** 提供了轻量安装方式（无需打包 `.nupkg`），从本地 `templates/` 目录直接注册到 `dotnet new`：

```powershell
dotnet new install ./templates/dora-node/
dotnet new install ./templates/dora-operator/
```

**smoke-csharp-bindings.ps1** 新增了模板验证步骤：

1. 检查模板是否已安装，未安装则自动安装
2. 创建 `dotnet new dora-node -n TestSmokeNode` 项目并 `dotnet build`
3. 创建 `dotnet new dora-operator -n TestSmokeOp` 项目并验证创建成功

### 5. 前端模板库集成

在 `doramate-frontend/src/utils/api.rs` 中新增 `builtin_csharp_templates()` 函数，返回两个 C# 模板配置条目，供前端"添加节点"面板使用：

```rust
pub fn builtin_csharp_templates() -> Vec<NodeTemplateConfigEntry> {
    vec![
        NodeTemplateConfigEntry {
            node_type: "csharp-simple-node".into(),
            name: "C# Simple Node".into(),
            description: "A simple C# Dora node with event handling".into(),
            icon: String::new(),
            path: None,
            inputs: Some(vec!["input".into()]),
            outputs: Some(vec!["output".into()]),
        },
        NodeTemplateConfigEntry {
            node_type: "csharp-operator".into(),
            name: "C# Operator (NativeAOT)".into(),
            description: "A C# Dora operator using NativeAOT".into(),
            icon: String::new(),
            path: None,
            inputs: Some(vec!["input".into()]),
            outputs: Some(vec!["output".into()]),
        },
    ]
}
```

### 6. Bug 修复与代码库审计

在实施过程中，对 `dora-api-csharp/` 进行了全面代码审计，发现并修复了以下问题：

**ArrowRecordBatchProjector 缺失投影方法：**

`ArrowRecordBatchRowAccessor`、`ArrowStructRowAccessor`、`ArrowRecordBatchColumnProjector`、`ArrowStructColumnProjector` 四个类中，部分 `TryGet*` 方法存在（`TryGetInt32`、`TryGetString`、`TryGetDecimal128`）而部分缺失。补充了 7 个缺失方法：

- `TryGetInt64`、`TryGetBoolean`、`TryGetFloat`、`TryGetDouble`
- `TryGetBinary`、`TryGetDate32`、`TryGetTimestamp`

**版本字符串不一致：**

`src/DoraOperator/DoraOperatorBinding.cs` 中的 `Version` 属性写死为 `"0.1.0"`，与 csproj 的 `<Version>0.2.0</Version>` 不一致。已同步为 `"0.2.0"`。

## 与计划规范的差异

| 计划规范 | 实际实现 | 原因 |
|---------|---------|------|
| 模板 API：`DoraNode.Create()` / `await node.RunAsync()` | 真实 SDK API：`new DoraNode.DoraNode()` / `node.Next()` 同步循环 | 计划中的简化 API 尚未实现 |
| template.json 符号：`namespace` 参数 | `NodeName` / `OperatorName` + `TargetFramework` 参数 | 实际 SDK 需要更具体的参数化 |
| 模板包 `identity` | `DoraNode.CSharp` → `DoraNode.Template` | 遵循计划规范更新 |
| csproj 使用 `.csproj.template` 扩展名 | 使用 `.csproj` 配合 `sourceName` 重命名 | `.template` 后缀不会被模板引擎自动剥离 |
| 模板包版本 `0.1.0` | `0.2.0` | 与全项目版本协调保持一致 |
| 脚本安装：`dotnet new install ./templates/` | `dotnet new install ./templates/dora-node/` + `dora-operator/` | 需分别安装每个模板，因为文件夹层级不同 |
| 前端 `NodeTemplateConfigEntry` 含 `id`/`language`/`category`/`template_source` | 使用现有 `NodeTemplateConfigEntry` 结构体（`node_type`/`name`/`description`/`icon`等） | 计划中的结构体字段与现有 `api.rs` 不匹配 |

## 使用指南

### 本地开发流程

```powershell
# 1. 构建原生库
pwsh ./scripts/build-native.ps1

# 2. 打包 SDK 到本地 NuGet 源
dotnet pack src/DoraNode/DoraNode.csproj -c Release -o artifacts/packages
dotnet pack src/DoraOperator/DoraOperator.csproj -c Release -o artifacts/packages

# 3. 安装模板
pwsh ./scripts/build-templates.ps1

# 4. 创建节点项目
dotnet new dora-node -n MyAnalysisNode
cd MyAnalysisNode
dotnet restore   # 从本地源 + nuget.org 解析依赖
dotnet build
```

### 用户快速开始

```powershell
# 确保已安装 DoraMate.Templates NuGet 包
dotnet new install DoraMate.Templates

# 创建 C# Dora 节点
dotnet new dora-node -n MyFirstNode
cd MyFirstNode
dotnet build
```
