## 新增文件清单（8 个）

### 1. `VERSION` — 版本号单一事实来源

```
0.9.0
```

所有组件的版本号以该文件为准。`build-release.ps1` 在构建时自动读取并做一致性校验。

### 2. `scripts/package-zip.ps1` — ZIP 打包脚本

**功能**：将构建产物打包为 `doramate-{version}-win-x64.zip`

打包内容：
```
doramate-0.9.0/
├── bin/
│   ├── doramate-localagent.exe    # LocalAgent 二进制
│   └── dora.exe                   # Dora CLI
├── frontend/                       # WASM 前端 dist
├── examples/                       # 示例数据流 YAML
├── tools/                          # 工具脚本（保留）
├── start.cmd                       # 启动脚本（含端口等待）
├── start-quick.cmd                 # 快速启动脚本
├── stop.cmd                        # 停止脚本
└── README.txt                      # 使用说明
```

**关键特性**：
- 自动创建标准目录结构
- 跳过不存在的文件（只警告，不中断）
- 输出 ZIP 文件大小统计
- 返回结果对象供父脚本使用

### 3. `scripts/package-installer.nsi` — NSIS 安装包脚本

**功能**：生成 Windows 安装程序 `doramate-{version}-setup.exe`

**安装行为**：
- 安装路径：`%PROGRAMFILES64%\DoraMate`
- 开始菜单快捷方式（DoraMate + Uninstall）
- 桌面快捷方式
- PATH 环境变量注册（可选）
- 注册表卸载入口（控制面板可卸载）

**卸载行为**：
- 删除所有安装文件
- 删除开始菜单和桌面快捷方式
- 清理注册表项
- 清理 PATH 环境变量

### 4. `scripts/build-release.ps1` — 一键发布构建

**执行流程**（6 步）：

```
Step 1: 版本一致性检查
  ├── 读取 VERSION (0.9.0)
  ├── 校验 LocalAgent Cargo.toml
  ├── 校验 Frontend Cargo.toml
  ├── 校验 DoraNode/DoraOperator csproj
  └── 不一致时询问是否继续

Step 2: 标准门禁验证（可选，-SkipTests 跳过）
  └── release-gate-local-runtime-standard.ps1 -Rounds 20

Step 3: 构建 LocalAgent (release)
  └── cargo build --bin doramate-localagent --release

Step 4: 构建前端 WASM (release)
  └── trunk build --release

Step 5: 构建 Dora CLI (release)
  └── cargo build -p dora-cli --release

Step 6: ZIP 打包（可选，-SkipPackaging 跳过）
  └── package-zip.ps1
```

**使用方式**：
```powershell
# 标准发布构建（含门禁验证）
./scripts/build-release.ps1

# 快速构建（跳过测试和门禁）
./scripts/build-release.ps1 -SkipTests

# 仅构建，不打包
./scripts/build-release.ps1 -SkipPackaging

# 指定版本号和输出目录
./scripts/build-release.ps1 -Version "0.9.1-rc.1" -OutputDir "C:\dist"
```

### 5. `scripts/start-doramate.cmd` — 用户启动脚本

用于安装后的桌面快捷方式和开始菜单启动。特性：
- 显示 DoraMate 标题和版本号
- 后台启动 LocalAgent
- 轮询端口 52100 等待就绪（避免打开空白页面）
- 就绪后自动打开默认浏览器
- 按任意键优雅停止

### 6. `scripts/stop-doramate.cmd` — 用户停止脚本

- `taskkill /F /IM doramate-localagent.exe`
- `taskkill /F /IM dora.exe`

### 7. `.github/workflows/release-packaging.yml` — 发布 CI

**触发条件**：推送 `v*` tag（如 `v0.9.1-rc.1`、`v1.0.0`）

**执行步骤**：
1. Checkout + Setup Rust（含 wasm32 target）
2. Setup .NET 8
3. 安装 `trunk`（WASM 打包工具）
4. Vendor Dora 源码并构建 Dora CLI
5. 调用 `build-release.ps1 -SkipTests` 构建并打包
6. 上传 ZIP 到 Actions artifacts
7. 从 `docs/CHANGELOG.md` 提取对应版本的发布说明
8. 创建 GitHub Release（含 ZIP 附件）

**手动触发**：也支持 `workflow_dispatch`（可指定版本号）

## 发布流程

### 发布 RC 版

```bash
git tag -a v0.9.1-rc.1 -m "DoraMate v0.9.1 Release Candidate 1"
git push origin v0.9.1-rc.1
```

CI 将自动构建、打包、上传到 GitHub Release（draft）。

### 手动构建

```powershell
# 完整构建（含门禁 20 轮）
./scripts/build-release.ps1

# 输出位置
#   out/dist/doramate-0.9.0-win-x64.zip
```

### 发布正式版

```bash
# 更新 VERSION → 1.0.0
# 更新所有 Cargo.toml / csproj
# 更新 CHANGELOG.md
git commit -m "chore: bump version to 1.0.0"

git tag -a v1.0.0 -m "DoraMate v1.0.0"
git push origin v1.0.0
```
