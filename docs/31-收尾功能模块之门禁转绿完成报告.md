## 代码改动

### 1. `.github/workflows/local-runtime-standard-release-gate.yml`

新增两个功能：

**E2E P0 前置检查（e2e-precheck job）：**
- 在跑 standard release gate 之前，先执行 `Invoke-Pester ./tests/e2e/LocalAgentE2E.Tests.ps1 -Tag P0`
- 如果 E2E P0 失败，gate 自动中止，避免在基础链路损坏的情况下空跑 50 轮
- 提供 `skip_e2e_precheck` 输入参数用于 triage/debug 场景

**趋势汇总步骤：**
- gate 完成后自动调用 `summarize-local-runtime-trends.ps1`
- 生成趋势 JSON + Markdown 报告并上传

### 2. `scripts/summarize-local-runtime-trends.ps1`

新增 `gate_green_readiness` 评估块：
```json
gate_green_readiness = {
    consecutive_passes_needed: 3,
    consecutive_passes_achieved: 0-3,
    latest_standard_passed: bool,
    standard_runs_completed: N,
    all_thresholds_strict: true,
    ready_for_release: bool
}
```

新增 Markdown 输出中的 **Gate-Green Readiness** 章节，包含发布 checklis：t
- Standard release gate passes 50 rounds @ 100%
- 3 consecutive full passes achieved
- E2E P0 tests pass
- Multi-dataflow baseline passes
