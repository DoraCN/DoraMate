## 1. 项目总体状况

### 1.1 项目定位

DoraMate 是面向 [DORA](https://github.com/dora-rs/dora)（Dataflow-Oriented Robotic Architecture）数据流的本地可视化编辑与运行工具链。核心路径为 **编辑 → 保存 → 运行 → 观察 → 停止**。

### 1.2 仓库组成

| 子项目 | 技术栈 | 说明 |
|--------|--------|------|
| `doramate-frontend` | Leptos 0.7 + WASM (CSR) | 可视化编辑器 |
| `doramate-localagent` | Axum 0.7 + Tokio | 本地代理 HTTP + WebSocket 服务 |
| `doramate-examples` | Rust + C# | 示例数据流 |
| `dora-api-csharp` | C# .NET 8 | Dora C# 语言绑定（Node / Operator SDK） |

### 1.3 架构特征

- **Rust 全栈**：前后端统一语言（已验证可行）
- **纯文件系统架构**：零数据库依赖（已验证可行）
- **本地代理模式**：浏览器 → `127.0.0.1:52100` → DORA runtime（已验证可行）
- **门禁体系完整**：PR gate → Standard release gate → E2E nightly → Trend summary

### 1.4 版本信息

所有组件已同步至 **v0.9.0**：

| 组件 | 文件 | 版本 |
|------|------|------|
| VERSION 源 | `VERSION` | `0.9.0` |
| LocalAgent | `doramate-localagent/Cargo.toml` | `0.9.0` |
| Frontend | `doramate-frontend/Cargo.toml` | `0.9.0` |
| DoraNode SDK | `dora-api-csharp/src/DoraNode/DoraNode.csproj` | `0.9.0` |
| DoraOperator SDK | `dora-api-csharp/src/DoraOperator/DoraOperator.csproj` | `0.9.0` |

## 5. 🟡 需要决策或入手的中间优先级事项

### 5.1 GitHub 仓库分支保护设置

- **来源**：docs/27 Section "主要风险与应对"、docs/23 Section 3.1
- **背景**：PR gate 已有 4 个 job（localagent-tests、frontend-tests、live-smoke、e2e-p0），但 GitHub 层面的 **required status checks** 尚未配置
- **需要配置为 required 的 checks**：
  - `windows-pr-localagent-tests`
  - `windows-pr-frontend-tests`
  - `windows-pr-live-smoke`
  - `windows-pr-e2e-p0`（建议但不强制）
- **注意**：需要仓库管理员权限（GitHub Settings → Branches → Branch protection rules）
- **预估**：15 分钟（需要管理员配合）

### 5.2 干净环境 ZIP 包验证

- **来源**：docs/27 最终发布前检查清单
- **检查项**：`ZIP 包在新装 Windows 机器上可运行`
- **要求**：
  - 解压 ZIP → 运行 `start.cmd` → 自动打开浏览器 → 能加载前端 UI
  - 验证 LocalAgent API 可用：`curl http://127.0.0.1:52100/api/health`
- **注意**：需要一台没有 Rust / .NET SDK 的干净 Windows 机器（或 VM）
- **预估**：30 分钟（含环境准备）

### 5.3 C# NuGet 包独立引用验证 ✅ 已解决

- **来源**：docs/27 最终发布前检查清单
- **检查项**：`C# NuGet 包可独立引用`
- **状态**：✅ 已验证通过
  ```powershell
  dotnet new console -n TestNode
  dotnet add TestNode/TestNode.csproj package DoraMate.DoraNode --source dora-api-csharp/artifacts/nuget/
  # → Installed DoraMate.DoraNode 0.9.0 ✅
  ```

### 5.4 .NET SDK 版本差异关注

- **当前状况**：
  - 本地开发环境：`.NET 10.0.100`
  - CI 环境：`.NET 8.0.x`（`actions/setup-dotnet@v4` 指定）
- **风险**：本地用 .NET 10 编译的 C# 二进制在 .NET 8 运行时可能有兼容性问题
- **建议**：确认 CI 中所有 `dotnet build` / `dotnet test` 都使用 `actions/setup-dotnet@v4` 指定的 .NET 8，避免不小心依赖了 .NET 10 的 API

### 5.5 `dotnet new` 模板安装状态确认

- **当前状况**：`dotnet new list` 显示 `dora-node` 和 `dora-operator` 模板已安装
- **需要确认**：在新 Clone 的仓库中重新运行 `install-templates.ps1` 是否能正常安装
- **建议**：在 CI 中增加 `dotnet new dora-node` → `dotnet build` 的验证步骤（当前在 nightly E2E 中有部分覆盖）

## 6. 🟢 低优先级或后续迭代事项

以下事项属于产品迭代范畴，建议在 v1.0 正式版发布后再规划。

### 6.1 跨平台支持（macOS / Linux）

- **原始目标**：docs/13 中提到 macOS `.dmg` 和 Linux `.deb/.rpm` 安装包
- **当前状态**：仅支持 Windows（LocalAgent 的 Windows 特定代码通过 `#[cfg(target_os = "windows")]` 条件编译，非 Windows 平台有 macOS/Linux 分支实现但未经验证）
- **建议**：在 v1.0 正式版之后，以 ZIP 分发为起点逐步扩展

### 6.2 更多 DORA 节点类型支持

- **原始目标**：docs/13 要求"支持至少 20 个常用 DORA 节点"
- **当前状态**：`doramate-examples` 主要包含 C# 示例节点，Python / Rust 原生节点示例有限
- **节点清单**：Camera (OpenCV)、YOLOv8、SAM2、Whisper、MediaPipe 等 20 个节点主要是 Python 生态节点
- **建议**：作为后续产品迭代，按实际用户需求逐步补充

### 6.3 dora-hub 节点市场集成

- **原始目标**：前端节点面板支持"从 dora-hub 获取节点列表"
- **当前状态**：未实现
- **建议**：在 v1.0 发布后视社区需求而定

### 6.4 Rust 编写的跨平台安装器

- **来源**：docs/27，风险 3 的应对方案
- **说明**：用 Rust 编写自定义安装器替代 NSIS，以获得跨平台（Windows/macOS/Linux）能力
- **建议**：成本较高，优先以 ZIP 分发为主，安装器为增强选项

### 6.5 Python 节点开发

- **背景**：DORA 生态中 Python 节点占比最高，但 DoraMate 当前主要支持 Rust 和 C#
- **当前能力**：LocalAgent 在 `check_node_process` 中已支持 Python 节点进程检测
- **建议**：根据社区用户实际需求决定优先级

### 6.6 前端功能增强

- **可能的方向**：
  - 自动布局算法优化（当前有 `apply_auto_layout`，拓扑排序层次布局）
  - 更多交互方式（键盘快捷键已实现，可以扩展）
  - 主题系统（当前为默认样式）
  - 国际化（当前仅中文文档）
- **建议**：在用户反馈收集后再规划

## 9. 发布流程速查

### 发布 RC 版

```bash
# 1. 确认所有改动已提交
git status

# 2. 打 tag 推送（自动触发 CI 构建 + GitHub Release）
git tag -a v0.9.1-rc.1 -m "DoraMate v0.9.1 Release Candidate 1"
git push origin v0.9.1-rc.1
```

### 手动本地构建

```powershell
# 完整构建（含门禁 20 轮验证）
./scripts/build-release.ps1

# 快速构建（跳过测试）
./scripts/build-release.ps1 -SkipTests

# 构建产出位置
#   out/dist/doramate-0.9.0-win-x64.zip
```

### 发布正式版

```bash
# 1. 更新版本号
#    VERSION → 1.0.0
#    所有 Cargo.toml / csproj 同步
#    CHANGELOG.md 新增 [1.0.0] 章节

# 2. 提交
git commit -m "chore: bump version to 1.0.0"

# 3. 打 tag + 推送
git tag -a v1.0.0 -m "DoraMate v1.0.0"
git push origin v1.0.0
```
